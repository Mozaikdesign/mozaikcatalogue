## State
Single-file tablet catalogue (`index.html`, about 3.3 MB). It holds 1,739 pieces from 13 brands: 1,477 live and 262 archived. There are no prices on the public link.
- **Live:** https://mozaikdesign.github.io/mozaikcatalogue/
- **Preview:** https://mozaikdesign.github.io/mozaikcatalogue/preview/ — same build as live.
- **Repo:** github.com/Mozaikdesign/mozaikcatalogue. Pages serves `main`, root folder.
- **Uploading:** in Chrome, use GitHub's upload page. The file must be staged into `/mnt/user-data/uploads` first, and you need a real click on "Commit changes".
